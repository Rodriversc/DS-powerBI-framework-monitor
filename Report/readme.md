# Power BI Report
 
The original Power BI report (`.pbix`) is not included in this repository due to confidentiality requirements.
 
The project was developed using company-related data and internal source information. Although the screenshots and supporting documentation in this repository have been anonymised, the original Power BI file may still contain embedded data, metadata, connection details or other information that cannot be shared publicly.
 
For this reason, only anonymised screenshots, the project assignment and presentation materials are included.
 
## What is available --> See Screenshots folder
 
- Anonymised dashboard screenshots
- Project assignment
- Presentation used to demonstrate the solution
- Documentation describing the project objectives and functionality
 
The report itself was created in Microsoft Power BI using Power Query, DAX, SQL and Deneb visualisations.
